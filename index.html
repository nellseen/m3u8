Core Pipeline

Cascading 6-Engine Fallback Pipeline

When a video stream URL arrives, the orchestrator cascades through 6 specialized extraction layers. If one engine encounters anti-bot shielding or unsupported protocols, failover to the next engine occurs in milliseconds.

ENGINE 01
Direct / HLS Detection
READY

High-speed parser for direct .m3u8 and .mp4 URLs. Performs zero-latency HTTP probe and immediate routing without launching heavyweight browser overhead.

Latency: <50ms · Fast Path
ENGINE 02 · DEEP INSPECTOR
Playwright + Chromium Network Sniffer
READY

Full headless browser automation tuned for PRoot & Linux ARM64/x64. Intercepts asynchronous XHR/fetch requests, decrypts dynamic manifest URLs, and extracts hidden video tags directly from the DOM before rendering completes.

PRoot-Safe Sandbox · Headless DOM Listener · Network Interception
ENGINE 03
Streamlink Processor
READY

Dedicated livestreaming engine optimized for live broadcast feeds, Twitch, Vimeo, and custom RTMP/HLS transport streams. Pipe segments directly with minimal buffer overhead.

Livestream Optimized · RTMP / HLS Streams
ENGINE 04
yt-dlp Universal Extractor
READY

Comprehensive fallback covering 1,000+ media sites. Enforces automatic bestvideo+bestaudio merging capped at 720p to preserve bandwidth and conform to mobile Telegram playback.

1000+ Portals · Format Fallback
ENGINE 05
FFmpeg HLS Direct Remux
READY

Native FFmpeg TS reassembly engine. Downloads individual transport stream (.ts) chunks, re-aligns Presentation Time Stamps (PTS), and outputs faststart MP4 containers.

PTS Alignment · Lossless Remux
ENGINE 06
Secondary Stream Retry
READY

Heuristic failover analyzing previously collected video candidates during the browser or network phase, re-attempting alternative bitrates if the master playlist drops connection.

Heuristic Fallback · Final Guard

Reliability & Bounds

Production-Hardened System Architecture

Built from first principles for resource-constrained environments including Termux on Android, low-cost VPS instances, and containerized Docker clusters.

Strict Max 720p Policy

Videos with resolution >720p (such as 1080p or 4K) are automatically scaled down to 720p preserving the native aspect ratio. Native videos $\le$ 720p are never upscaled, avoiding artifacting and unnecessary CPU burn.

Per-Task Scratch Isolation

Every download creates an isolated sandbox directory (source, download, processed, thumbnail, logs). Regardless of whether an engine succeeds or fails, temporary files are guaranteed purged on task exit.

Process Tree SIGKILL Cleanup

Subprocesses (Chromium, FFmpeg, yt-dlp, Streamlink) are tracked with dedicated AbortController instances. On timeout or cancellation, parent and child PID trees receive immediate termination to prevent zombie memory leaks.
